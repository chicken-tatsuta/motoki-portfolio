# Motoki Tatsuta Portfolio

企画・デザイン・技術を横断してきた取り組みを、背景・役割・プロセス・成果・学びまで伝えるReact製ポートフォリオです。

## ローカル起動

```bash
npm install
npm run dev
```

## AI利用の開示

- 使用ツール: OpenAI Codex（GPT-5）
- 使用日: 2026年7月20日・8月7日
- 使用範囲: 情報設計、文章初稿、Reactコードの雛形・主要ロジック、CSS実装、テスト補助
- プロンプト概要: 提出済みコンセプトを維持し、元ポートフォリオの構成・配色・書体を尊重しながら、課題ルーブリックに沿って内容設計・UX・レスポンシブを改善し、Reactで再構築する
- 確認: 生成内容は制作者本人が検証・修正し、最終成果物に責任を持つ

既存の本人制作物・本人所有画像のみを使用し、AI生成画像や第三者素材は使用していません。
